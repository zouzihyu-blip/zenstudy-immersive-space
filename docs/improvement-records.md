## 改善紀錄一：解決瀏覽器背景分頁休眠導致的計時器飄移與延遲
- **原本問題**：
  在初版計時器開發時，採用傳統 JavaScript 的 `setInterval(fn, 1000)` 每秒遞減 `timeRemaining--`。但在實際讀書測試中發現：當使用者將分頁切換至後台查閱文獻，或筆電進入節能模式時，現代瀏覽器（Chrome/Edge）會啟動 Timer Throttling 機制，將計時器頻率強制降至 1 分鐘甚至停止執行。導致原本設定 25 分鐘的番茄鐘，實際過了 35 分鐘才響起，嚴重影響學習節奏。
- **改了什麼（設計決定）**：
  重構計時核心模組（`js/timer.js`）。揚棄簡單的秒數計數器，改採**時間戳差值計算（Delta Timing）**架構：
  1. 在計時器啟動時記錄 `expectedEndTime = Date.now() + (remainingSeconds * 1000)`。
  2. 即使背景執行緒被降頻，每次喚醒時均以 `Date.now()` 的絕對真實時間計算剩餘毫秒數 `Math.ceil((expectedEndTime - now) / 1000)`。
  3. 將檢查頻率提升為每 250ms 檢查一次，確保切回前景瞬間立即補正至真實秒數。
- **怎麼確認（驗證結果與證據）**：
  1. 在 Chrome 中開啟 ZenStudy 計時器並點擊「開始專注（25:00）」。
  2. 將分頁切換至背景長達 5 分鐘，同時在另一分頁觀看影片。
  3. 5 分鐘後切回 ZenStudy 分頁，時間精準停在 `20:00`，誤差小於 0.2 秒。
  4. 分頁標題即時動態顯示 `(19:59) 專注中 · ZenStudy`，證明背景計時完全精準無漂移。

## 改善紀錄二：從外部音訊檔案轉向 Web Audio API 程序化聲學合成，杜絕版權與載入卡頓
- **原本問題**：
  原構想是透過網路引入雨聲、海浪與壁爐等 MP3 音訊檔案。然而在試用時遇到三重痛點：
  1. 外部免費音檔常遭遇 CORS 跨網域阻擋或因第三方伺服器不穩導致載入 404 報錯。
  2. 離線環境（如圖書館 Wi-Fi 斷線或無網路自習）下無法播放任何環境音。
  3. MP3 循環播放時在結尾與開頭銜接處有明顯的 0.5 秒停頓爆音，破壞讀書沉浸感。
- **改了什麼（設計決定）**：
  打造純前端程序化聲學合成引擎（`js/audio-engine.js`），全面改用瀏覽器原生 **Web Audio API**：
  1. 利用數學演算法即時產生粉紅噪音（Pink Noise）與布朗噪音（Brown Noise）緩衝區。
  2. 串接低通濾波器（BiquadFilterNode）與隨機脈衝生成器，即時合成「細雨聲」與「壁爐劈啪聲」。
  3. 利用低頻振盪器（LFO）週期性調節波形振幅，創造如同大自然呼吸起伏的「海浪潮汐聲」。
  4. 提示音採用多重正弦波諧波（A3 220Hz 疊加 2.76x、5.4x 諧波），模擬西藏頌缽（Singing Bowl）的沉穩餘韻。
- **怎麼確認（驗證結果與證據）**：
  1. 在完全斷開網路連接的離線狀態下載入網頁，點擊「🌧️ 細雨連綿」與「🪵 溫暖壁爐」，聲音立即流暢播放，無任何網路依賴。
  2. 連續播放 30 分鐘，波形平滑無接縫，徹底消除 MP3 循環重播的卡頓噪聲。
  3. 計時結束時，西藏頌缽以自然指數衰減（Exponential Decay）延續 4.5 秒，聽覺反饋溫和且不驚嚇。

## 改善紀錄三：從單純介面展示升級為完整的四合一資料管理系統（CRUD），滿足期末加分最高標準
- **原本問題**：
  初期版僅有固定的靜態場景與固定計時器，使用者無法依據自己的讀書計畫自訂內容。若重新整理頁面，所有專注狀態與學習心得便全數丟失；且未能滿足期末評分標準中「管理／資料功能（CRUD）需能實際新增、編輯或刪除資料並即時在畫面呈現保存」的加分要求。
- **改了什麼（設計決定）**：
  建立獨立的 `Storage` 資料管理模組（`js/storage.js`），打造四大實用管理介面：
  1. **待辦目標管理 (Tasks CRUD)**：可新增任務、指定分類標籤與預估番茄數、編輯、切換勾選完成、刪除任務，並可錨定為「當前專注任務」。
  2. **靈感隨手便箋 (Notes CRUD)**：可新增多色便箋、即時自動存檔（Auto-save）、切換色系與刪除便箋。
  3. **自訂場景庫 (Scenes CRUD)**：除 8 款預設場景外，使用者可輸入任何圖片/影片 URL 自訂新場景，並可隨時刪除。
  4. **專注歷史紀錄 (History CRUD)**：番茄鐘完成時自動寫入學習歷程（時長、任務名稱、日期時間），可個別刪除或匯出完整 JSON 備份檔。
- **怎麼確認（驗證結果與證據）**：
  1. 在網頁中新增任務「商業設計期末作業」，預估 3 顆番茄。
  2. 在便箋中隨手寫下「靈感重點：少即是多」。
  3. 重新整理（F5）瀏覽器，兩項資料立即從 LocalStorage 重新讀取並完整呈現，狀態毫無遺失。
  4. 點擊「📥 匯出完整 JSON 備份」，成功下載 `.json` 檔案；使用無痕視窗開啟並點擊「📤 匯入 JSON 備份」，所有資料完美還原。

## 改善紀錄四：視覺眩光與視覺雜訊干擾，導入「商業設計深色磨砂美學」與「Zen 極簡沉浸模式」
- **原本問題**：
  一般番茄鐘與讀書軟體充斥著高對比按鈕、大量邊框與突兀的色彩，在夜晚或昏暗環境下長時間注視螢幕會造成嚴重的視覺疲勞（Visual Fatigue）；此外過多的按鈕會持續分散閱讀者的注意力，難以真正「沉浸」。
- **改了什麼（設計決定）**：
  從商業設計系視覺傳達角度進行全盤美學重構（`css/styles.css`）：
  1. **Glassmorphism 毛玻璃語言**：採用曜石黑（Deep Obsidian Dark `#0a0b0e`）作為基底，搭配半透明磨砂毛玻璃（`backdrop-filter: blur(24px)`）與微弱高光邊框（`border: 1px solid rgba(255,255,255,0.12)`）。
  2. **Zen 極簡沉浸模式（Zen Mode）**：設計一鍵隱藏機制（按 `Z` 鍵或點擊「👁️ 極簡專注」），瞬間以淡入淡出動畫隱藏頂部導覽列、底部音效面板與待辦清單，中央卡片轉為完全透明，僅保留流暢呼吸的發光進度環與時鐘。
  3. **自訂環境光感**：在底部控制列加入「背景亮度（Brightness: 20%~100%）」與「景深模糊（Blur: 0~16px）」雙滑桿，讓使用者自由依環境光線壓暗背景。
- **怎麼確認（驗證結果與證據）**：
  1. 在夜晚實測開啟「深夜東京」場景，將亮度滑桿拉至 40%、模糊滑桿調至 4px，背景霓虹燈轉為柔和環境光，眼睛不適感顯著下降。
  2. 按下鍵盤 `Z` 鍵，介面在 0.28 秒內平滑過渡為全黑沉浸空間，視覺焦點 100% 集中於讀書計時。
  3. 滑鼠移動至右上角即浮現「✕ 退出極簡」提示，亦可按 `Esc` 瞬間回復，操作極致自然。
