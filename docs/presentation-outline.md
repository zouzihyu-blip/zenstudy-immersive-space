### 投影片 2：選題動機與痛點分析 (Design Motivation)
- **背景痛點**：
  1. **數位干擾嚴重**：手機與社群通知不斷打斷閱讀與設計構思。
  2. **環境噪音紛擾**：咖啡廳聊天聲或室友走動容易破壞專注。
  3. **現有工具過於冰冷繁瑣**：市面上的計時軟體缺乏美感，反而帶來壓迫感。
- **核心設計哲學**：
  - 「少，但是更好（Less, but better）」— 打造一個沒有雜音、視覺純粹、隨開即用的個人心流錨點。
- **口講要點（1 分鐘）**：
  > 身為設計系學生，在做設計或考前衝刺時，最渴望的就是一個能讓心靜下來的空間。「ZenStudy」的誕生，就是希望能透過視覺氛圍與自然環境音的包覆，讓任何人在一秒鐘內進入專注心流。

### 投影片 3：產品架構與功能亮點 (Core Features)
- **四大核心模組**：
  1. **多感官氛圍場景**：8 款精選高解析度動態場景＋自訂場景庫。
  2. **Web Audio 原生聲學混音器**：8 軌獨立環境白噪音＋Lo-Fi 和弦＋西藏頌缽提醒。
  3. **防休眠精準三大計時器**：番茄鐘（25/5/15）、倒數限時衝刺、自主正數碼表。
  4. **完整的資料管理 CRUD 系統**：待辦目標清單、靈感隨手便箋、專注歷史紀錄與 JSON 備份。
- **口講要點（1.5 分鐘）**：
  > ZenStudy 不只是一個計時器，它整合了視覺、聲音與思緒整理。接下來我們將進行現場功能 Live Demo。

### 投影片 8 ~ 9：期末必備真實改善紀錄（4 大項）
- **改善紀錄 1：計時器在背景分頁休眠時的漂移問題**
  - *問題*：`setInterval` 在分頁背景休眠時會被瀏覽器降頻，導致 25 分鐘番茄鐘大幅延誤。
  - *決定*：改用 `Date.now()` 時間戳差值運算（Delta Timing），每次喚醒立即計算絕對秒數。
  - *驗證*：切換分頁 5 分鐘後切回，時間精準無任何誤差。
- **改善紀錄 2：環境音依賴外部 MP3 易遇版權與 CORS 斷線**
  - *問題*：外部音訊常因跨域或無網路而報錯失效，循環處有卡頓停頓感。
  - *決定*：全面導入 Web Audio API 程序化合成，純演算法產生雨聲、海浪與頌缽。
  - *驗證*：離線斷網下 100% 順暢播放，循環平滑無接縫。
- **改善紀錄 3：從單純展示升級為四大資料管理系統（CRUD）**
  - *問題*：原版本缺乏個人化儲存，重整即遺失，未達期末加分規定的資料管理標準。
  - *決定*：實作待辦清單、靈感便箋、自訂場景與歷史紀錄，並加入 JSON 備份匯出匯入。
  - *驗證*：實測新增與編輯資料，F5 重新整理後 LocalStorage 完整復原，JSON 備份匯出成功。
- **改善紀錄 4：長時閱讀視覺疲勞與介面雜訊過多**
  - *問題*：傳統軟體介面繁瑣高光，長時間注視產生眩光與注意力分散。
  - *決定*：導入曜石黑毛玻璃美學、背景暗度調節滑桿，以及一鍵按 `Z` 的「Zen 極簡沉浸模式」。
  - *驗證*：顯著降低視覺刺激，獲取最純淨的讀書體驗。
- **口講要點（2 ~ 3 分鐘）**：
  > 這四項改善紀錄紀錄了我們從初版試用、發現問題、提出設計對策，到最後嚴格驗證的完整歷程。
